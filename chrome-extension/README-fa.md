# افزونهٔ اتصال GptApiYar به Chrome فعلی

این افزونه فقط برای صفحهٔ محلی `http://127.0.0.1:8787/demo.html` نوشته شده و **به ChatGPT یا افزونهٔ اشتراکی دیگر دسترسی ندارد**.

1. برنامهٔ Spring Boot روی پورت 8787 و React روی 5173 را اجرا کن.
2. در Chrome اصلی (همان پروفایل فعلی) وارد `chrome://extensions` شو، Developer mode را روشن کن.
3. Load unpacked و پوشهٔ `D:\ChatGPT_Projects\GptApiYar\chrome-extension` را انتخاب کن.
4. روی آیکون افزونهٔ GptApiYar کلیک کن. از داخل آن صفحهٔ تست را در همان Chrome باز کن و تب را بازخوانی کن.
5. توکن محلی را وارد کن (مقدار آزمایشی فعلی `dev-change-this-token` است؛ برای استفادهٔ واقعی `GATEWAY_TOKEN` را تغییر بده). روی اتصال کلیک کن.
6. در React حالت «Chrome فعلی (افزونه)» را انتخاب کن. بعد از چند ثانیه وضعیت Connected نمایش داده می‌شود.
7. یک پیام متنی بفرست؛ پاسخ شبیه‌سازی‌شده از همان تب برمی‌گردد.

اگر صفحه را Refresh کنی، باید از داخل popup دوباره «اتصال» بزنی. این رفتار عمدی است تا تب بدون تأیید دوباره فعال نشود. برای جلوگیری از دسترسی ناخواستهٔ سایت‌های دیگر، دسترسی افزونه در manifest فقط به localhost:8787 محدود است.

**محدودیت‌ها:** این مسیر فعلاً فقط متن و صفحهٔ تست محلی را پشتیبانی می‌کند؛ فایل، تصویر، ویس و سایت‌های ثالث به آن اضافه نشده‌اند. مسیر CDP قبلی همچنان موجود است. اسکریپت نصب افزونه را خودکار در مرورگر فعال نمی‌کند؛ انتخاب Load unpacked باید توسط خود کاربر انجام شود. هیچ Git Commit یا Push انجام نمی‌شود.
